## The goal

A personal website that doesn't look like a template – it looks like me. Fast, bilingual, usable by everyone – and built so I can extend it myself at any time.

## The challenges

- **Speed:** The site doesn't need heavy frameworks. JavaScript only loads when it's actually needed – for example for the command palette or the terminal.
- **Two languages:** Every page exists in German and English, with its own URL and correct metadata for search engines.
- **Usable by everyone:** Keyboard navigation, screen reader support, enough contrast and respect for anyone who prefers less motion.
- **Easy to maintain:** All texts live in two clear files. New projects and blog posts are simple text files.

## The extras

- **Command palette:** Press <kbd>⌘</kbd> <kbd>K</kbd> or <kbd>Ctrl</kbd> <kbd>K</kbd> to jump anywhere.
- **Terminal mode:** Press the key left of <kbd>1</kbd> and use the website like a command line.
- **Reaction game:** My first project – reimagined.
- **Live status:** Local time in Zug and whether I'm available right now.
- **CV as PDF:** generated automatically from the same data on every publish.

## Built with AI – honestly

I built this website together with an AI coding assistant. I set the content, goals and direction, made the decisions and learned how a professional website is put together along the way: from components to search engine optimisation to accessibility. Working well with AI tools is, for me, one of the most important skills of a modern software engineer.

## What I learned

A good website is more than a nice design. Load time, accessibility, security and maintainability decide whether it really works – for every visitor, on every device.
