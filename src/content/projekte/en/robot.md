## The idea

My very first project: a small robot that isn't remote-controlled but decides for itself where to go.

## What it can do

- **Drive:** It moves forward on its own.
- **Steer:** It changes direction by itself.
- **See:** It senses its surroundings through sensors.

## What I learned

With a robot, hardware and software have to work together perfectly. When something doesn't work, the bug might be in the code – or in a cable. This project showed me that I don't just want to use technology, I want to build it.
